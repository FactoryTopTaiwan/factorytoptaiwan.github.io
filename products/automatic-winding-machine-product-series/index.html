    Product description

    What this machine does

    • Family overview of automatic winding machines covering armature, in-slot and out-slot stator, hook-type armature, needle-winding, and multi-axis coil configurations.
    • Servo-driven wire placement, programmable tension, and 360-degree hooking geometry available across the family.
    • Each machine in the series is configurable for the customer's motor architecture and wire gauge; see the individual machine pages for detail.
    • Machines are supplied as standalone units or integrated into a modular winding line.
    • Configuration and cycle time are project-dependent.

    Specifications

    What this machine is rated for

    • Coverage: armature winding, stator winding (in-slot and out-slot), hook-type, multi-axis coil
    • Drive: servo per axis
    • Tension: programmable, per-stage
    • Hooking: configurable to 0.01 degree where the process supports it
    • Integration: standalone or in-line

    Capabilities shown are typical. Values outside this range can be quoted on request.
