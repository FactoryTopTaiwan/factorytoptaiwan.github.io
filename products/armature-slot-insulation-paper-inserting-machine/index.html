    Product description

    What this machine does

    • This model can be connected with the robot arm and the conveyor belt to achieve fully automatic production function.
    • Equipped with pressure safety device. The machine will stop immediately when copper wire is being over coiled or insertion jam in tooling or silicon steel plate is deformed or insert pressure is bigger than setting pressure. This is not only to protect the product and tooling but also the machine itself.
    • High operating stability and efficiency. The fastest insertion speed is 0.3 second per slot. Take 12-slot rotor for example, 6.7 seconds can compete one rotor (the fastest).
    • Optional PLC with HMI control which making the operating experience more humanize.
    • Suitable for unskewed rotor and skewed rotor.
    • CAM driven for slot changing and insertion synchronously, which simplifies the complexity of the mechanism and easy to maintenance.
    • Automatic slot change, push and claw positioning and high accuracy in repetitive.

    Specifications

    What this machine is rated for

    • Workpiece: brushed / DC / universal motor armatures
    • Material: reel-fed insulation paper (project-dependent thickness)
    • Operations per cycle: automatic feed, cut, form (U-shape), insert - all slots
    • Tooling: modular, exchangeable per slot count and stack height
    • Automation: standalone or integrated into an armature production line

    Capabilities shown are typical. Values outside this range can be quoted on request.
