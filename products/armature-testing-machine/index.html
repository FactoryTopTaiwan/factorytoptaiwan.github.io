    Product description

    What this machine does

    • 1. Layers short circuit testing composition：
    • (1). Testing waveform: 1.2x40Μs
    • (2). Testing voltage: 100~1500Vp.p. Operate through manual setup on setup panel. Present in digital form , accuracy: ±5% Of F.S.
    • (3).Identify: After reading the inrush current value by PLC, making OK/NG judgment with the benchmark. And record the test value.
    • (4).Testing frequency: 4 times on 90 degree; 1 time on 180 degree.
    • (1).Testing Method: between commutator and shaft.
    • (2). Testing Voltage: AC100~1500V. Adjust voltage manually and analog voltage meter. Accuracy: ±5% Of F.S.
    • (3). Leakage current Setting: 0.5/1/2/5/10mA , 5 section setting. Accuracy: ±1% Of F.S.
    • (4). Automatic circuit inspection: Operate through manual setup on setup panel. When circuit leakage reaches to max. per setup, alarm automatically. PLC reads signal.
    • 3. DC Resistance Test：
    • (1). Testing Method: DC constant current is applied to the coil under test and adopt the four-terminal method for detection.
    • (2). Testing Range: 10~1000.0mΩ, 1~10Ω with 20°C automatic temperature compensation.
    • (3). Accuracy: ±0.5% of F.S.
    • (4). Result judgment: The test value is read by the PLC and it is automatically compared with upper and lower limit values stored in the internal storage.
    • (5). Testing frequency: commutator

    Specifications

    What this machine is rated for

    • Workpiece: completed brushed / universal motor armatures
    • Tests: surge test, insulation resistance, DC resistance (project-dependent test suite)
    • Judgement: automatic pass / fail with unit-level diversion
    • Interface: PLC with touchscreen HMI, recipe management per part number
    • Automation: standalone or in-line as end-of-line inspection

    Capabilities shown are typical. Values outside this range can be quoted on request.
