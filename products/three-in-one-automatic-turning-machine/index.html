    TWM-LA01

    Three in one automatic turning machine

    TWM-LA01 is a three in one automatic turning machine built by Teamwork Automation in Taichung, Taiwan. Supplied as a standalone machine or integrated into a complete production line.

    Product description

    What this machine does

    • Combines three armature turning operations - commutator OD, armature core OD, and shaft end - in a single fixture on one machine.
    • Servo-driven cutting head with programmable feed rate, engineered for consistent surface finish across all three diameters.
    • Loading, indexing and unloading are automated so an operator can supervise multiple machines; suits medium to high-volume carbon-brush armature production.
    • Cycle time depends on armature geometry and target finish; configurable for project-specific tolerances on request.
    • Designed for integration into a rotor production line or run as a standalone workstation.

    Specifications

    What this machine is rated for

    • Workpiece: DC and universal motor armatures with a commutator
    • Operations per cycle: three (commutator OD, armature OD, shaft)
    • Drive: servo motor per axis
    • Automation: automatic feeding, indexing and unloading
    • Control: PLC with touchscreen HMI, project-configurable recipes

    Capabilities shown are typical. Values outside this range can be quoted on request.
