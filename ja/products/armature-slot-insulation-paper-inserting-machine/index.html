    TWM-IP01

    Armature slot insulation paper inserting machine

    TWM-IP01 is a armature slot insulation paper inserting machine built by Teamwork Automation in Taichung, Taiwan. Supplied as a standalone machine or integrated into a complete production line.

    製品概要

    この機械の機能

    • 電機子スロットに絶縁紙を自動供給・切断・成形・挿入する装置です。
    • サーボ制御による挿入で、絶縁紙の折れやずれを抑えます。
    • ブラシ付モーター・直流モーターの電機子生産に対応します。

    仕様

    この機械の対応範囲

    • Workpiece: brushed / DC / universal motor armatures
    • Material: reel-fed insulation paper (project-dependent thickness)
    • Operations per cycle: automatic feed, cut, form (U-shape), insert - all slots
    • Tooling: modular, exchangeable per slot count and stack height
    • Automation: standalone or integrated into an armature production line
